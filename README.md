# Drug Side Effect Prediction Using CS-LSTM and CS-CNN

## Overview

This project focuses on predicting potential drug side effects using two deep learning approaches: CS-LSTM and CS-CNN. The approaches combine deep learning models with Cosine Similarity to analyze drug and side-effect data.

## Dataset

The project uses the SIDER dataset containing drug names and associated side effects.

## Methodology

1. Data acquisition
2. Handling missing values
3. Removal of stop words and special characters
4. Feature extraction using TF-IDF
5. Similarity validation using Cosine Similarity
6. Tokenization and sequence preparation
7. LSTM model development
8. CNN model development
9. Model evaluation using Accuracy, Precision, Recall and F1 Score

## Technologies Used

* Python
* TensorFlow / Keras
* LSTM
* CNN
* TF-IDF
* Cosine Similarity
* NLTK
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn

## Project Outcomes

The comparative study evaluated CS-LSTM and CS-CNN approaches for drug side-effect prediction. According to the project results, CS-LSTM achieved 92% accuracy while CS-CNN achieved 90% accuracy.
